# 🎮 Tic Tac Toe – Python Game

A fun and simple **Tic Tac Toe** game with a colorful interface built using **Python**, **OOP**, and **Tkinter**.  
Play against an **AI opponent** that picks moves automatically!



## 🚀 Features
- Two players: **You** vs **AI**
- Colorful and clean GUI using Tkinter
- Automatic AI response after your move
- Win/Draw detection
- Easy to reset and play again! 


## 🛠️ Tech Stack
- **Python 3**
- **Tkinter** (built-in GUI library)
- **OOP** design for modularity
- Basic AI logic (random move – can be improved)
