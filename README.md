# 🎮 Code w El3b

Welcome to **Code w El3b** — a fun little collection of games I built for learning and creativity.  
It combines **Python** and **Unity** projects, each made to explore something new.  
Every game is a new experiment and a chance to learn something new.  
✨ Because coding is always more fun when you *code and play!*

---

- `Educational Kids Game :` Educational game for kids with three engaging mini-games: Puzzle, Memory Match, and Math Fun. Kids can create their own avatars, and learn through play with colorful graphics and cheerful sound effects.
