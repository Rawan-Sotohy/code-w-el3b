# 🐦 Flappy Bird

**A classic Flappy Bird clone made with Unity - Tap to flap and survive!**

## 📖 About The Game

**Flappy Bird** is a recreation of the popular mobile game where you control a bird navigating through columns. Tap to make the bird flap its wings and fly through the gaps without hitting the obstacles!

---

## ✨ Features 

### Core Gameplay:
- ✅ **Bird Physics** - Gravity and flapping mechanics
- ✅ **Column System** - Spawns at fixed/random intervals
- ✅ **Collision Detection** - Bird collides with columns and ground
- ✅ **Scrolling Background** - Creates infinite scrolling effect
- ✅ **Camera Boundaries** - Bird stays within camera frame

### Game States:
- ✅ **Playing State** - Normal gameplay with scrolling
- ✅ **Die State** - Stops scrolling when bird dies
- ✅ **Restart System** - Press SPACE to reload scene

### Column Generation:
- ✅ Instantiates at proper intervals (prevents overlap)
- ✅ Random y-position within reasonable range
- ✅ Maintains consistent gap between top and bottom columns

### UI Elements:
- ✅ "Game Over" message on death
- ✅ "Press SPACE to restart" instruction

---

## 🛠️ Technologies Used

- **Unity Engine** - Game development platform
- **C#** - Programming language
- **Unity Physics 2D** - Collision and rigidbody
- **Unity UI** - Game Over screen
- **Unity Scene Management** - Scene reloading

---
## 🎮 How to Play

### Controls:
- **SPACE** - Make the bird flap
- **SPACE** (when dead) - Restart the game
