# 🐱 Meow Adventure

**An exciting adventur game - Play and enjoy endless adventures!**

## 📖 About The Game

**Meow Adventure** is a fun adventure game where you play as Kitty on a journey filled with challenges and surprises! Collect points, avoid obstacles, and explore different worlds in this exciting adventure.

### ✨ Key Features

- 🎮 **Smooth Controls** - Easy to learn, satisfying to master
- 🏆 **Score System** - Collect points and rewards
- 🎨 **Beautiful Graphics** - Colorful and attractive design
- 🔊 **Sound Effects** - Immersive audio experience
- ⚡ **Multiple Levels** - Increasingly challenging gameplay
- 
---

## 🎯 How to Play

### Basic Controls:
- ➡️ **Right Arrow** - Move right
- ⬆️ **Space** - Jump

### Objectives:
1. ✅ Collect all fish and rewards
2. ❌ Avoid obstacles and enemies
3. 🏁 Reach the end of each level
4. 🌟 Achieve the highest score
